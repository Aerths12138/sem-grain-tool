# SEM Grain Tool Web v1.0.0

这是 SEM Grain Tool 的首个完整本地网页版发布。程序仍然完全在本机运行：双击
Windows EXE 后，会启动仅监听 `127.0.0.1` 的服务并自动打开浏览器。

## 下载选择

- `SEMGrainToolGPU.7z.001`、`.002`……：推荐版本。内置 CUDA 11.8，同时支持
  CPU 自动回退，共 11 个分卷。
- `SEMGrainToolCPU.7z.001`、`.002`……：纯 CPU 版本，体积较小，不需要 NVIDIA
  显卡或驱动，共 5 个分卷。
- `SHA256SUMS.txt`：所有发布文件的 SHA-256 校验值。

两个版本都采用约 256 MiB 的分卷。必须下载所选版本的全部分卷并放在同一目录，
然后使用 7-Zip 从 `.001` 开始解压。

不要只复制解压目录中的 EXE；`_internal` 文件夹必须与 EXE 一起保留。

## 本次功能

- 浏览器内完成图像上传、标尺标定、CPSAM/Cellpose 分割和结果预览
- 掩膜删除、合并、新增、分割以及撤销/重做
- 颗粒面积、质心、等效直径和粒径分布统计
- 圆形重建、毫米单位 DXF 和元数据 JSON 导出
- 独立检测 NVIDIA 驱动、CUDA 和显存
- 显存低于 4 GB、无驱动或 CUDA 检测失败时自动切换 CPU
- GPU 推理失败后自动进行一次 CPU 重试
- 本地随机访问令牌、任务取消、超时和子进程树清理

## 已验证

- CPU 与 CUDA 两套 PyInstaller 构建验收通过
- 网页端自动化测试 7/7 通过
- CPU 和 GPU 成品均完成真实启动、本地 HTTP 访问及关闭验证
- 当前测试机的 NVIDIA MX350（2 GB）会按设计进入 CPU 安全模式
